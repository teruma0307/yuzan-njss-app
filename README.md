# 雄山 NJSS入札案件抽出MVP

株式会社雄山（防衛省発注の建設工事に入札資格を持つ会社）向けに、NJSS（入札情報速報サービス）
からエクスポートした入札案件CSVを読み込み、雄山が資格を持つ工事種別×発注機関「防衛省」の案件
（および全省庁統一資格で応札できる役務案件）を抽出し、締切が近い案件を可視化するMVPです。

（同じ「AIの作業場」内の`ai_reselling_starter`はポンプアップのeBay転売用の別アプリで、
入札には関与しません。ポンプアップは入札に一切関与していないため、このプロジェクトは
雄山専用として構築しています。）

## 他のパソコンでも使う（配布用exe・推奨）

Python環境を各パソコンに用意しなくても使えるよう、単体で動くexeファイルを用意しています。

`雄山NJSS案件抽出_配布用` フォルダ（中に`雄山NJSS案件抽出.exe`と`config`フォルダが入っています）を
**丸ごと**USBメモリ等でコピーして、別のパソコンのデスクトップなどに置いてください。

1. コピーした `雄山NJSS案件抽出_配布用` フォルダを開く
2. `雄山NJSS案件抽出.exe` をダブルクリック（`config`フォルダは同じ場所に置いたままにしてください）
3. 「WindowsによってPCが保護されました」という青い画面が出た場合は、
   `詳細情報`→`実行`をクリックしてください（署名していない社内ツールのため毎回この確認が出ます）
4. 黒い画面が開いてしばらくすると、ブラウザが自動的に開きます
5. 初回だけ「Email:」と聞かれることがあります。何も入力せずEnterでスキップしてください

コピー先のパソコンにPythonをインストールする必要はありません。**フォルダごとコピーすること**
（exeファイル単体だけを渡すと`config`が見つからずデフォルト設定で動いてしまいます）。

exeを作り直す（コードを更新した場合）には、開発環境（このフォルダ、`.venv`がある方）で以下を実行します。

```bash
.venv\Scripts\activate
pyinstaller --noconfirm --onefile --name "雄山NJSS案件抽出" --add-data "app.py;." --add-data "src;src" --collect-all streamlit --collect-all altair --collect-all pyarrow --hidden-import streamlit.web.cli run_standalone.py
```

`dist\雄山NJSS案件抽出.exe` が新しく作られるので、`雄山NJSS案件抽出_配布用`フォルダの中身を差し替えてください。

## Windowsでの起動（開発環境・このパソコン用）

1. このフォルダをVS CodeまたはClaude Codeで開く
2. `setup_windows.bat` をダブルクリック（VS Codeの中でファイルをダブルクリックしても
   編集画面が開くだけで実行されません。Windowsのファイルエクスプローラーで実行してください）
3. 完了後、`run_app.bat` をダブルクリック
4. ブラウザで画面が開いたら、NJSSからエクスポートした実際のCSVをアップロード

## 手動起動

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## CSV必須列（2026-07-30に実際のNJSSエクスポートCSVで確認済み）

- 案件ID
- 案件名
- 案件概要URL
- 機関
- 履行/納品場所
- 案件公示日
- 入札日
- 資料等提出日
- 入札資格
- 業種
- 予定価格

**列の対応関係の注意点（実データ確認で判明した事実）:**
- 「開札日」に相当する列は存在しません。一般競争入札では「入札日」が実質的な開札日を兼ねています。
- 「申込締切日」に相当する列もありません。代わりに「資料等提出日」（参加資格審査書類等の提出期限）
  があり、これが実質的な行動締切です。空欄の案件は「入札日」を代わりに使います
  （`src/csv_import.py`の`normalize_bids`で自動フォールバック）。
- 「業種」列は1案件に複数カテゴリが改行区切りで入っており、表記は「舗装工事」のように
  「工事」が付く形式です（資格審査結果通知書の「舗装」という表記とは完全一致しません）。
- 「入札資格」列に、求められる資格区分・等級の生テキストが入っています
  （例:「防衛省競争参加資格 建設・土木・工事系 A/B/C/D」「全省庁統一資格 役務の提供系 A/B/C/D」）。
  ただし1案件に複数の資格系統が混在することがあり、機械的な等級判定はしていません。

## 抽出条件の設定（`config/filter_settings.json`）

```json
{
  "target_organizations": ["防衛省"],
  "target_industries": ["土木一式", "大工", "とび・土工・コンクリート", "石", "管", "タイル・れんが・ブロック", "鋼構造物", "鉄筋", "舗装", "しゅんせつ", "機械器具設置", "水道施設", "解体"],
  "unified_qualification_keywords": ["全省庁統一資格"],
  "min_estimated_price_jpy": 0,
  "max_estimated_price_jpy": null,
  "qualification_expiry_date": "2027-03-31"
}
```

- `target_organizations`: 発注機関名の部分一致キーワード。地域では絞りません（防衛省案件は全国に点在するため）。
- `target_industries`: 資格審査結果通知書に記載された工事種別13種。**単純な部分一致ではなく、
  改行・「・」区切りのカテゴリ単位で完全一致判定しています**（後述の誤検出対策）。
- `unified_qualification_keywords`: 雄山は全省庁統一資格（物品・役務、等級D）も保有しているため、
  「入札資格」列にこのキーワードを含む役務案件（撤去・据付作業、看板撤去等）も候補に含めます。
  業種条件を満たさなくても、この条件を満たせば候補になります（OR条件）。
- `qualification_expiry_date`を過ぎると、他の条件を満たしていても候補は自動的に0件になり、
  画面上に警告が表示されます（資格の再取得後、日付を更新してください）。

根拠は2026-07-30にユーザーから提供された「資格審査結果通知書」（防衛省整備計画局建設制度官発行、
令和7年3月24日付、有効期限令和9年3月31日＝2027-03-31、全省庁統一資格は等級D・全国有効・
令和10年3月31日まで）です。塗装を含め通知書に記載のない工事種別は対象外です。

**等級（ランク）は自動判定しません。** 「入札資格」列の生テキストをそのまま画面に表示するので、
応札前に必ず案件詳細URLと合わせて人が確認してください。

**業種マッチングの誤検出対策**: 実データ検証で、単純な部分一致だと「管」が「指定管理」に、
「大工」が「大工道具」に誤って一致することが判明したため、`src/bid_filter.py`の
`_industry_matches`はカテゴリ・トークン単位の完全一致（「工事」suffixを補って比較）で判定します。
実際のCSVで新しい表記パターンが見つかった場合はこの関数の調整が必要になることがあります。

## 現段階で行うこと

- NJSS案件CSVの読込・必須列バリデーション・列名正規化
- 発注機関（防衛省）＋（雄山の資格業種 or 全省庁統一資格の役務案件）＋資格有効期限による候補案件抽出
- 資料等提出日（無ければ入札日）を基準にした締切ハイライト表示
- 画面上での応札検討承認（チェックボックス）
- 承認済み案件CSVの出力

予定価格が非公表（空欄）の案件は自動除外せず候補に残します（金額を推測で埋めることはしません）。
なお2026-07-30に確認した実際のCSV（受付中案件）では、予定価格・落札価格ともにほぼ全件非公表でした。

## 落札金額の予測について（意図的に実装していません）

「いくらで入札すれば取れるか」を予測する機能は実装していません。受付中の案件には予定価格・
落札価格の情報がなく、断定的な金額を提示するのは事実に基づかない推測になるためです
（CLAUDE.mdの最重要ルール）。NJSSで「落札結果」（開札・契約済み案件）のCSVを別途エクスポート
いただければ、類似の過去案件の実際の落札価格・落札会社を事実として一覧化する機能は追加できます。
